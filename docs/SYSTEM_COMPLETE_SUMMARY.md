⚛️ QUANTUM ALGORITHMS IMPLEMENTED
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. QAOA (Quantum Approximate Optimization)
   ├─ Circuit: p=2 layers with REAL Qiskit
   ├─ QUBO: Encodes shift requirements + constraints
   ├─ Optimizer: COBYLA with 1024 shots
   ├─ Fallback: Classical greedy for >20 qubits
   └─ Result: Optimal shift assignments

2. Grover's Algorithm (√N Search)
   ├─ Method: Oracle-based amplitude amplification
   ├─ Applications: Find specialists, available doctors, emergency team
   ├─ Advantage: O(√N) instead of O(N)
   └─ Result: Matched doctors with priority scoring

3. VQE (Variational Quantum Eigensolver)
   ├─ Ansatz: EfficientSU2 with 2 reps
   ├─ Hamiltonian: Ising model for workload
   ├─ Optimizer: L_BFGS_B (classical)
   └─ Result: Minimized variance in workload distribution

4. Quantum Annealing (Simulated)
   ├─ Temperature: 100.0 → 0.01 (cooling 0.995)
   ├─ Energy: Constraint violations + imbalance
   ├─ Metropolis: exp(-ΔE/T) acceptance
   └─ Result: Refined schedule through energy minimization

5. Amplitude Amplification
   ├─ Method: Boosts favorable state probabilities
   ├─ Criteria: Experience, emergency priority, availability
   ├─ Amplification: O(√N/M) speedup
   └─ Result: Priority-based doctor selection

ORCHESTRATION: QAOA → Grover → VQE → VQE → Annealing → Format
