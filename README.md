# Quantum-Based Patient Room Allocation

A React dashboard concept for quantum-inspired patient room allocation and rescheduling. It includes a multi-page layout with a scheduling board, optimization insights, room availability, and patient info views.

## Features
- Multi-page navigation for Dashboard, Patients Info, Rooms, Analytics, and Settings
- Scheduling grid with mock assignments and availability slots
- Optimization insights with summary cards and charts
- Responsive layout tuned for desktop and tablet

## Getting Started
1. Install dependencies:
   - npm install
2. Start the dev server:
   - npm run dev
3. Build for production:
   - npm run build
